# Vórtex Screen

**Graba tu pantalla, sin límites.** App de Vortex Company, parte de la suite Vórtex Studio.

Grabadora de pantalla y cámara con MediaRecorder.

- **PC**: graba pantalla completa, ventana o pestaña con `getDisplayMedia`, con audio del sistema/pestaña opcional — ideal para tutoriales.
- **Android**: modo cámara (frontal/trasera) para grabar vídeo con `getUserMedia`, con guía del grabador nativo del sistema para la pantalla del móvil.
- Calidad 720p / 1080p / 1440p / máxima, pausa y continuar, cronómetro.
- Descarga del vídeo en **.webm** o **.mp4** según el soporte del navegador, con aviso automático si MP4 no está disponible.

## Características

- Gratis, sin anuncios y sin cuentas de usuario.
- Todo el procesamiento ocurre en tu navegador: ninguna foto, grabación o texto se sube a ningún servidor.
- Funciona en PC y móvil (los permisos de cámara/micrófono se piden solo cuando los usas).
- Soporte oficial: [vortexmusic.soporte.app@gmail.com](mailto:vortexmusic.soporte.app@gmail.com)
